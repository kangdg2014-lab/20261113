# 🏛️ 지도 위에 피어나는 우리 동네 보물창고 — 참여형 3D 국가유산 웹 전시

> **대한민국 3D 지도 기반 참여형 국가유산(문화·자연·무형) 큐레이션 & 게이미피케이션 웹 전시 프로젝트**

본 프로젝트는 **[국가유산청 국가유산포털의 공식 국가유산 유형분류 체계](https://www.heritage.go.kr/heri/html/HtmlPage.do?pg=/cul/cultureEasySub01_01.jsp&pageNo=1_4_1_0)**와 **[국립중앙박물관](https://www.museum.go.kr/) · [국가유산 디지털 서비스](https://digital.khs.go.kr/)**의 공신력 있는 자료를 바탕으로 제작된 디지털 3D 웹 전시입니다.

---

## ✨ 핵심 기능

1. **국가유산청 공식 유형분류 체계 전면 적용 (`국가유산기본법` 기준)**
   - **국가지정유산 (7대 종목)**: `국보`, `보물`, `사적`, `국가민속문화유산`, `명승`, `천연기념물`, `국가무형유산`
   - **시·도지정유산 및 유산자료 (7종)**: `시도유형문화유산`, `시도민속문화유산`, `시도기념물`, `시도문화유산자료`, `시도자연유산`, `시도자연유산자료`, `시도무형유산`
   - **등록유산 (2종)**: `국가등록문화유산`, `시도등록문화유산`
   - **비지정유산 (2종)**: `일반동산문화유산 (문화유산법 제60조)`, `매장유산 (매장유산법 제2조)`
2. **밝고 화사한 3D 한반도 지도 & 360° 입체 뷰어 + 실제 사진 갤러리**
   - Three.js(`r128`) 기반의 3D 입체 지도 및 유산 모델 뷰어와 함께 실제 촬영 사진을 다중 첨부하고 확대 감상할 수 있습니다.
3. **십이지신(12간지) × 4단계 생애주기(아기~노년) 사용자 아이콘 생성기**
   - 쥐·소(송아지~노소)·호랑이(개호주~백호 산신령)·토끼·용·뱀·말(망아지~노마)·양·원숭이·닭(병아리~노계)·개(강아지~수호견)·돼지 12종 × 4단계 생애주기 캐릭터 커스터마이징을 지원합니다.
4. **계정 ID 기반 진행상황 영구 유지 및 일일/주간 참여 쿼터**
   - 사용자 계정 ID별로 미션·점수·스탬프·캐릭터가 자동 유지되며, JSON 백업 코드로 기기 간 이동이 가능합니다.
   - **댓글 작성**: 하루 최대 2회 제한 / **유산 등록**: 일주일 최대 2회 제한
5. **6단계 상세 주소 입력기**
   - `시/도` + `시/군/구` + `읍/면/동` + `도로명` + `건물번호` + `상세주소` 전체 체계를 지원합니다.

## 🚀 GitHub 업로드 및 GitHub Pages 배포 방법

1. 본 압축 파일(`our_town_heritage_github_repo.zip`)의 압축을 해제합니다.
2. GitHub에서 새 저장소(Repository)를 생성한 뒤 아래 파일들을 그대로 업로드(Commit & Push)합니다:
   - `index.html` (웹 전시 실행 파일)
   - `README.md` (저장소 메인 설명서)
   - `our_town_heritage_3d_exhibition_spec.md` (기획 및 기능 명세서)
   - `sources.md` (공식 참고 기관 및 출처 기록)
   - `todo.md` (향후 고도화 과제 기록)
   - `.nojekyll` 및 `.gitignore`
3. GitHub 저장소 상단 **Settings → Pages** 메뉴에서 **Branch**를 `main` (`/root`)으로 설정하고 **Save**를 클릭하면 `https://<계정아이디>.github.io/<저장소명>/` 주소로 즉시 공개 웹 전시가 열립니다.
