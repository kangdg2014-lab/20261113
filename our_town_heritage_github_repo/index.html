🐙 깃허브(GitHub) 업로드 안내 및 계정 백업/복원

1. GitHub 저장소 업로드 및 GitHub Pages 무료 배포 방법

  1. 함께 생성된 our_town_heritage_github_repo.zip 압축을 풀거나, 이 웹앱 파일 이름을 index.html로 저장합니다.
  2. GitHub에서 새 Repository(예: korea-3d-heritage-exhibition)를 생성하고 index.html, README.md, sources.md, todo.md 파일을 업로드(Commit & Push)합니다.
  3. 저장소 상단 Settings → Pages → Branch를 main (/root)으로 선택 후 Save를 누르면 1분 뒤 공개 웹 주소(https://아이디.github.io/저장소명/)가 생성됩니다.

2. 내 계정 진행상황 백업 코드 내보내기 / 불러오기 (기기 간 이동 지원)

동일 브라우저에서는 localStorage를 통해 내 계정(@donggeon02)의 미션·댓글·유산 등록 상태가 자동 유지됩니다. 다른 PC나 스마트폰에서도 이어서 하려면 아래 백업 코드를 복사해 붙여넣으세요.
